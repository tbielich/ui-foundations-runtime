  Use semantic tokens, keep pattern responsibilities clear, and build on semantic HTML. Apply these principles when choosing or changing a pattern.
</p>

## Applying the principles

Apply these principles through:

- pattern and component documentation
- token-driven state, color, spacing, and typography decisions
- semantic HTML and accessibility expectations
- rule-pipeline traceability
- validation and CI checks

When contributing a pattern, cite the principle IDs required by the rule
pipeline so reviewers can follow the reason for each rule.
