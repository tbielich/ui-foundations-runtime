<div class="docs-home-hero">
  <h1>UI Foundations</h1>
  <p>A token-first design system that provides components and tools to help product teams work more efficiently and make applications more cohesive across brands and platforms.</p>
</div>

<div class="docs-home-section">
  <h2>Foundations</h2>
  <div class="docs-principle-grid">
    <div class="docs-principle-card">
      <h3>Rational</h3>
      <p>Use token roles and documented pattern behavior to guide interface decisions.</p>
    </div>
    <div class="docs-principle-card">
      <h3>Inclusive</h3>
      <p>Semantic HTML, keyboard access, and assistive-technology support are baseline requirements.</p>
    </div>
    <div class="docs-principle-card">
      <h3>Focused</h3>
      <p>Deliver what is needed, when it is needed. No unnecessary decoration or irrelevant content.</p>
    </div>
  </div>
</div>
